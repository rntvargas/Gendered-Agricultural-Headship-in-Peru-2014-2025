# Publication package for GitHub

This repository package contains the journal manuscript, its LaTeX source, scripts, figures, aggregate results, provenance checks, and documentation. It contains no person-level ENA data.

The exact version archived at Zenodo is [10.5281/zenodo.24395430](https://doi.org/10.5281/zenodo.24395430). This GitHub package adds the repository URL to the manuscript's availability statement and should be treated as a subsequent repository copy, not as an exact byte-for-byte copy of the Zenodo archive.

## Upload

1. Extract the ZIP locally.
2. Copy the *contents* of `github_ready_2014_2025` into the root of `https://github.com/rntvargas/Gendered-Agricultural-Headship-in-Peru-2014-2025`.
3. Commit the files. Do not add `.sav` inputs or any `LOCAL_ONLY.csv` files.
4. Check that `manuscript.pdf`, `manuscript.tex`, `README.md`, `CITATION.cff`, and `LICENSE.md` appear at the repository root.

The manuscript is 2014-2025 in scope, with no 2020 ENA round. The 2025 service-access component is separate from the historical series. The original construction of the 2014-2024 consolidated SPSS input remains unavailable in this public package; see `README.md` and `SUBMISSION_READINESS.md` before journal submission.
